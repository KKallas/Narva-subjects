# Robootika suvelaager — õppekava

Maht kokku: **6 tundi** (kaks päeva, kummalgi 3 tundi).

| Teema | Maht | Õppejõud |
|---|---|---|
| **Sissejuhatus liidesesse ja seadistamisse.** Robotkäe ülevaade, MQTT käsud, Pythoni loogika, GitHubi repo loomine. Guided practice | 0.5 | [Lektor] |
| **Pildituvastus ja arvutinägemine.** QR koodide lugemine, LUT teisendused, kaamera ja maailma vaheline kalibreerimine. Praktikum | 1 | [Lektor] |
| **Tehisintellektiga programmeerimine.** Claude Code aitab koodi kirjutada, sina kontrollid milline lahendus käivitub. Praktikum | 1 | [Lektor] |
| **Iteratiivne arendus ja versioonihaldus.** Git harud, tagasiside tsüklid, enda lahenduste kontroll. Praktikum | 1 | [Lektor] |
| **Autonoomne juhtimine ja otsustusloogika.** Mudelipõhine kogumine, ajalimiidiga töötamine, eri väärtustega koodid. Praktikum | 1 | [Lektor] |
| **Võistlus ja strateegia.** Kahe meeskonna matšid, vastasega arvestamine, efektiivne vs robustne lahendus. Praktikum | 1.5 | [Lektor] |

## Õpiväljundid

- Mõistab inimese ja masina koostöö põhiprintsiipi: vastutus jääb inimesele
- Juhib tööstuslikku robotkätt (Dobot MG400) MQTT käskude ja Pythoni loogikaga
- Kasutab tehisintellekti programmeerimiskaaslast (Claude Code) ja oskab pakkumusi kriitiliselt hinnata
- Kasutab versioonihaldust (Git/GitHub) muudatuste haldamiseks
- Lahendab arvutinägemise ülesandeid (QR koodid, LUT teisendused, kalibreerimine)
- Töötab tagasiside-põhises iteratsioonis ja teeb teadliku valiku efektiivse vs robustse lahenduse vahel
- Sõnastab probleeme nii, et tehisintellekti vastus oleks kasulik
